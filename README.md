# Iron Night

WWII tank survivor-like for Android: one thumb drives the platoon leader, the wingmen hold formation, every turret aims
on its own. Five minutes of night, waves of Panzer IV, Tiger and PaK 40, level-up cards, dawn at 5:00.

- `unity/` — Unity 6 (URP) project. Open `Assets/_Game/Scenes/Battle.unity`; everything is built in code on Play.
- `art/` — models, textures and the local generation pipeline (`art/pipeline/README.md`).
- `mockup/` — the HTML mockups the design was tested with.
- `docs/` — design document and screenshots.

Builds: menu *Iron Night > Build Windows / Build Android APK*, or headless with `IronNight.EditorTools.BuildTools`.
